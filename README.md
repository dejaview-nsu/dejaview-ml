# dejaview-ml

ML-ядро DejaView: превращение запросов и фильмов в векторы и поиск ближайших совпадений.

## Зона ответственности

- Эмбеддинги по модальностям: текст, изображение, кадры видео, аудио
- Обработка медиа: извлечение ключевых кадров из видео, признаков из звука
- Векторный поиск и оценка качества выдачи по каждому режиму
- Подготовка и обновление векторного индекса каталога

## Стек

Python · HuggingFace · векторный поиск (pgvector / Qdrant)

## Ссылки

- Проект: https://github.com/dejaview-nsu
- Контракты API и соглашения команды: https://github.com/dejaview-nsu/dejaview-docs

## Как работаем

- Ветка от `main`: `feat/...`, `fix/...` (нейминг — в соглашениях)
- Изменения только через Pull Request с ревью; прямой push в `main` закрыт

Структура проекта появится вместе с командой.
